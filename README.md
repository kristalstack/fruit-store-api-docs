# Fruit Store API Documentation

Developer documentation for a REST API built as part of my software development training.

The Fruit Store API supports product management, authentication, authorization, purchases, invoices, and caching.

## Technologies

- Python
- Flask
- PostgreSQL
- SQLAlchemy
- JWT
- Redis

## Documentation

- Getting Started
- Authentication
- API Reference
- Error Handling
- Troubleshooting

## About this project

This documentation portfolio is based on a backend API I developed during my software development training.

The project includes CRUD operations for fruit products, JWT-based authentication and authorization, role-based access, purchases and invoices, and Redis caching with cache invalidation.
